Lab 03 Reflection

In Lab 03, I learned and practiced how to use CSS to make my webpage look different. After spending time learning and practicing, I can now change colors, spacing, and layout.

I also learned how to use class and id selectors to style different parts of the page. This helped me understand how HTML and CSS work together. Overall, this lab helped me make my page look more clean and professional.

What I Learned

  1. I learned how to link a CSS file to my HTML.
  2. I learned how to change colors and spacing.
  3. I learned how to use class and id to style parts of the page.

Best Design Practices Reflection

In Lab 05, I learned that good design is not just about how a website looks but also how easy it is to use. A good website should have clear navigation, readable text, and enough spacing.I also learned about making websites for bot phones and computers. This lab helped me understand how design makes a website better for users.

What I Learned

  1. I learned that navigation should be clear and easy to follow.
  2. I learned that spacing and readable text make a webpage better.
  3. I learned that responsive design helps a page work on different screen sizes.
