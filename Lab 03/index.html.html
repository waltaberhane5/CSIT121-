Lab 02 Reflection

In this lab, I practiced building a webpage using correct HTML structure. Writing everything by hand helped me understand how webpages are organized.

What I Learned

  1. I learned headers and that there are 6 levels.
  2. Markup languages are directions that tell the browser how to display a webpage.
  3. I learned how important it is to pay attention to small details like file names and folder names.

Lab 03 Reflection

In Lab 03, I learned and practiced how to use CSS to make my webpage look different. After spending time learning and practicing, I can now change colors, spacing, and layout.

I also learned how to use class and id selectors to style different parts of the page. This helped me understand how HTML and CSS work together. Overall, this lab helped me make my page look more clean and professional.

What I Learned

  1. I learned how to link a CSS file to my HTML.
  2. I learned how to change colors and spacing.
  3. I learned how to use class and id to style parts of the page.
